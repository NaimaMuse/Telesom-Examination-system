# Unified Teacher My Course

The teacher workspace is `/teacher/my-course`. It keeps the existing green course hero, course information, overview cards and responsive tab layout.

## Tabs

- **Overview**: selected course, batch and academic year; existing course information; total/completed/remaining contract days; lesson progress; upcoming exams, quizzes and assignments.
- **Course Outline**: the existing contract/outline components embedded in My Course. Create/edit outlines, upload/download existing PDF/DOCX documents, add lessons, edit schedules, complete/reverse lessons, publish outlines, and manage existing additional contract lessons. Completed lesson schedules must be reversed before changing their planned dates. Completion history is retained.
- **Study Notes**: real, persistent learning materials using the existing Note model. PDF, DOC, DOCX, PPT and PPTX files up to 15 MB are stored privately in MongoDB. Metadata can be edited without replacing a file; removing a material archives it and preserves its stored file. Student downloads enforce course/year/batch enrollment.
- **Students**: enrolled students for the selected assigned course, academic year and batch, with duplicate enrollment rows removed from the display.
- **Assessments**: reuse existing assessment management and gradebook components. Display/manage exams, native quizzes, assignments and other activities; switch to Results & Marks without leaving My Course. Shared assessments without a batch remain available across their applicable course/year cohorts, but the gradebook roster is restricted to the selected batch.

Course/batch/year selection is shared across the tabs. Existing contracts remain selectable when a cohort has multiple contract periods. New cohorts are derived from real assignments, enrollments and contracts; no batches or contracts are generated by opening the page. Unauthorized course/year/batch/contract requests are rejected by the API.

## Completion and preservation

The existing lesson-status API and contract service remain authoritative. Completing several lessons on the same actual Nairobi teaching day counts once per contract; reversing the last completed lesson for a date restores the day. Completing a lesson updates the embedded outline, Overview contract balance and course progress immediately. No approval step was introduced.

No existing contract, outline, lesson, completion-history record or uploaded outline document was replaced or migrated. The original Teaching & Outlines implementation remains available to the Admin and is reused in the teacher's Course Outline tab. The teacher sidebar's separate Teaching & Outlines item was removed only after migration tests passed.

Old teacher links redirect rather than fail:

- `/teacher/outlines` → `/teacher/my-course?tab=outline`
- `/teacher/contracts` → `/teacher/my-course?tab=overview`

Existing URL cohort/contract filters are preserved by redirects. Dashboard links now point directly to the My Course outline tab. Unsaved notes, outline forms, assessment forms and marks prevent accidental course/tab switching until saved or cancelled.

The former My Course notes uploader stored only local browser state and did not persist document bytes. The replacement stores new uploads using the existing Note collection; it does not fabricate or reconstruct files that were never stored. Existing private Note records remain private and unchanged.

Student attendance routes, management and recording behavior were not modified. Attendance remains Admin-only.

## Main files

- `frontend/src/pages/teacher/MyCourse.jsx`: shared scope, five tabs and persistent notes UI.
- `frontend/src/components/TeacherContracts.jsx`, `AcademyWorkspace.jsx`: embedded contract summary, outlines, schedule editing and immediate balance updates.
- `frontend/src/pages/teacher/TeacherExams.jsx`, `TeacherResults.jsx`: optional cohort scope and draft protection, while preserving their existing standalone pages.
- `frontend/src/components/DashboardLayout.jsx`: teacher sidebar and backwards-compatible redirects.
- `backend/services/teacherCourseWorkspaceService.js`: assigned course/year/batch resolution and unified reads using existing models.
- `backend/controllers/teacherDashboardController.js`: existing My Course API integration and optional gradebook cohort filtering.
- `backend/controllers/courseMaterialController.js`, `backend/models/Note.js`: persistent document management on the existing Notes model.
- `backend/routes/academyRoutes.js`: safe lesson schedule editing without replacing completion history.
- `backend/routes/studentPortalRoutes.js`: enrolled students' learning-material access.
- `backend/services/teacherPerformanceService.js`: deterministic current-year enrollment selection when historical enrollments coexist.
